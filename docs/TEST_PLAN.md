# برنامه تست

## خودکار — بدون Unity (اجرا شده)
`./tools/run-logic-tests.sh` — ۴۴ تست روی `Core`: ترتیب هدف‌ها، پاداش فقط یک‌بار، تکرار، رها کردن، اتصال به آبادانی، حد آستانه‌ها، داده خراب/ناقص، پیشنهاددهنده، شکل‌دهی فارسی.
`python3 tools/validate_repo.py` — فایل‌های لازم، JSON، ارجاع‌های مأموریت، اسکن Secret.
`./tools/typecheck-unity-code.sh` — بررسی نوع‌ها در برابر استاب دست‌نویس (جایگزین کامپایل واقعی Unity نیست).

## خودکار — داخل Unity (هنوز اجرا نشده؛ نیاز به مجوز)
Workflow «Unity tests»: EditMode شامل `MissionJsonTests` (JsonUtility، رفت‌وبرگشت ذخیره، وجود فونت).
PlayMode تست‌ها هنوز نوشته نشده‌اند.
