# برنامه تست

## خودکار — بدون Unity (اجرا شده)
`./tools/run-logic-tests.sh` — ۷۲ تست روی `Core` (شامل ثبت اجراها و تحلیل علاقه): ترتیب هدف‌ها، پاداش فقط یک‌بار، تکرار، رها کردن، اتصال به آبادانی، حد آستانه‌ها، داده خراب/ناقص، پیشنهاددهنده، شکل‌دهی فارسی.
`python3 tools/validate_repo.py` — فایل‌های لازم، JSON، ارجاع‌های مأموریت، اسکن Secret.
`./tools/typecheck-unity-code.sh` — بررسی نوع‌ها در برابر استاب دست‌نویس (جایگزین کامپایل واقعی Unity نیست).

## خودکار — داخل Unity (هنوز اجرا نشده؛ نیاز به مجوز)
Workflow «Unity tests»: EditMode شامل `MissionJsonTests` (JsonUtility، رفت‌وبرگشت ذخیره، وجود فونت).
PlayMode تست‌ها هنوز نوشته نشده‌اند.

## دستی روی گوشی (نیازمند تست کاربر)
- [ ] نصب APK و باز شدن منوی اصلی
- [ ] «بازی جدید» → انتخاب دختر/پسر → ورود به محله
- [ ] **حروف فارسی به‌هم‌چسبیده و درست‌جهت** در منو، HUD، گفتگو (مهم‌ترین ریسک)
- [ ] جوی‌استیک، چرخش دوربین با لمس سمت راست، هم‌زمان
- [ ] پس از گرفتن مأموریت «جعبه‌ابزار گمشده»، نوار «راهنما» زیر هدف، فلش و فاصله را نمایش می‌دهد و با چرخاندن دوربین جهت فلش تغییر می‌کند؛ با نزدیک‌شدن، پیام «هدف نزدیک است» نمایش داده می‌شود.
- [ ] دکمه تعامل ظاهر می‌شود نزدیک استاد بهروز/وسایل
- [ ] مأموریت ۱ → ۲ → ۳؛ پاداش و نشان
- [ ] مدرسه پس از مأموریت ۳ ظاهراً زنده می‌شود (رنگ، پنجره‌های روشن، درخت، پرچم)
- [ ] از ابتدا با شغل غیر از مهندس (مثلاً کشاورز) شروع کن؛ باید ممکن باشد
- [ ] یک مرحله را تمام کن و دوباره از همان NPC بگیر؛ فهرست «جدید/دوباره» دیده شود
- [ ] وسط مأموریت با «کار دیگری می‌خواهم» شغل را عوض کن
- [ ] منو ← مأموریت‌ها ← «گزارش من»: نمودار، درصد، دقیقه و جمله‌های فارسی درست‌جهت
- [ ] خروج کامل و ورود دوباره: سکه، مأموریت‌ها، مدرسه حفظ شده
- [ ] رفتن به پس‌زمینه و برگشت
- [ ] دکمه Back اندروید منوی توقف را باز می‌کند
- [ ] نرخ فریم، دمای گوشی، مصرف RAM (مدل گوشی را یادداشت کنید)
