# آزادی انتخاب شغل و گزارش علاقه/پیشرفت

## قوانین بازی (آزادی کودک)
- **همهٔ ۷ شغل از ابتدا باز است**؛ کودک می‌تواند با هر شغلی شروع کند (فقط مرحله‌های داخل یک شغل پشت‌سرهم باز می‌شوند، چون هر مرحله به قبلی تکیه دارد).
- **هر مرحله تمام‌شده قابل تکرار است** (پاداش تکرار کمتر؛ XP، نشان و آبادانی دوباره داده نمی‌شود).
- هر NPC فهرست «مرحله‌های جدید + مرحله‌های قابل تکرار» را نشان می‌دهد؛ کودک خودش انتخاب می‌کند (۳ مورد در هر صفحه).
- وسط یک مأموریت می‌توان با «کار دیگری می‌خواهم» به شغل دیگری رفت. رها کردن **جریمه ندارد**.

## چه چیزی ثبت می‌شود (فقط روی خود گوشی)
برای هر بار انجام: مأموریت، شغل، **زمان واقعی بازی** (نه زمان منوها/گفتگوها)، موفق یا رهاشده، و تکراری‌بودن.
- `SaveData.attempts` — آخرین ۳۰۰ بار (برای مقایسهٔ اول و آخر).
- `SaveData.jobStats` — جمع‌های دقیق هر شغل (با پاک‌شدن سوابق قدیمی از بین نمی‌رود).
- ذخیره‌های قدیمی (نسخهٔ ۱) بدون مشکل بالا می‌آیند؛ تعداد انجام‌ها از `timesCompleted` خوانده می‌شود.
- رهاسازی کمتر از ۱۰ ثانیه و بدون پیشرفت (لمس اتفاقی) ثبت نمی‌شود؛ هر اجرا حداکثر ۳۰ دقیقه حساب می‌شود.

## نحوهٔ تحلیل (`InterestAnalyzer`، قابل‌آزمون و توضیح‌پذیر)
| معیار | تعریف |
|---|---|
| **علاقه** | ۴۰٪ سهم زمان + ۳۵٪ سهم **تکرارهای داوطلبانه** + ۲۵٪ سهم تعداد دفعات. سیگنالِ بدون داده حذف و وزن‌ها بازنرمال می‌شوند. |
| **موفقیت** | نرخ تمام‌کردن = انجام‌شده ÷ (انجام‌شده + رهاشده)؛ فقط برای شغل‌های با حداقل ۲ بار تلاش. |
| **پیشرفت** | مرحله‌های تمام‌شده از کل؛ و مرحله‌هایی که آخرین اجرا حداقل ۱۵٪ سریع‌تر از اولین اجرا بوده. |
| **اطمینان** | ۰ داده / کم (<۴) / متوسط (<۱۰) / زیاد. |

خروجی: ردیف‌بندی شغل‌ها + جمله‌هایی مثل «به نظر می‌رسد بیشتر به … علاقه نشان داده‌ای» و «بیشترین وقتت صرف … شده ولی در … موفق‌تر بوده‌ای».
**حد ادعا (سند §۱۱.۴):** فقط رفتار بازی را توصیف می‌کند؛ از «استعداد/هوش/شخصیت/ضعف» استفاده نمی‌شود و تست خودکار آن را تضمین می‌کند. نتیجهٔ تشخیصی یا پزشکی نیست.

## کجا دیده می‌شود
- منوی اصلی ← «گزارش من» (برای والدین هم مناسب).
- حین بازی ← منو ← «مأموریت‌ها» ← «گزارش من».
