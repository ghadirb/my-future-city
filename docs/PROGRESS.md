# پیشرفت

آخرین به‌روزرسانی: ۱۲ اکتبر ۲۰۲۶

## مرحله ۰ — بررسی و امکان‌سنجی — تکمیل‌شده
- مخزن اختصاصی ساخته شد (قبلاً مخزنی برای این بازی نبود).
- Unity `6000.3.11f1` انتخاب شد (LTS). شواهد: چند پروژه عمومی با GameCI و همین خط 6000.3 اندروید می‌سازند. **وجود دقیق ایمیج Docker این پچ تأیید نشده**؛ اولین اجرای واقعی نشان می‌دهد.
- بیلد ابری: GameCI (`unity-builder@v4`). نیازمند Secret مجوز Unity — **مانع فعلی**.
- ریسک‌ها: ۱) مجوز Unity، ۲) کامپایل نشدن کد در Unity واقعی (هنوز تست نشده)، ۳) نمایش متن فارسی روی دستگاه، ۴) حجم/زمان بیلد IL2CPP.

## مرحله ۱ — پروژه و اولین APK — ناقص (مسدود)
| کار | وضعیت |
|---|---|
| پروژه Unity، asmdef، manifest، تنظیمات اندروید در `BuildScript` | نوشته شده، در Unity اجرا نشده |
| صحنه آغازین/منو، جهان سه‌بعدی، شخصیت، دوربین، جوی‌استیک | نوشته شده، اجرا نشده |
| Workflow ساخت APK | نوشته شده، **هرگز اجرا نشده** |
| APK | **وجود ندارد** |
| معیار: اجرای واقعی Workflow + APK قابل دریافت + نصب روی گوشی | **برآورده نشده** |

**اقدام لازم از شما:** تنظیم Secretهای Unity طبق `docs/BUILD_ANDROID.md`.

## مراحل ۲ و ۳ — محله اول، مأموریت، ذخیره — کد نوشته شده، اثبات‌نشده
- منطق (مأموریت، پاداش، تکرار، ذخیره، آبادانی): **با ۴۴ تست واقعاً پاس شده**.
- اتصال به صحنه، UI، تعامل: فقط type-check با استاب دست‌نویس؛ در Unity اجرا نشده.
- محتوا: ۱ حرفه (مهندس و سازنده)، ۳ مأموریت، ۱ NPC، ۱ ساختمان تغییرپذیر (مدرسه).

## بعدی
1. تنظیم Secret → اجرای Build Android → رفع خطاهای کامپایل/بیلد احتمالی.
2. تست دستی روی گوشی (`docs/TEST_PLAN.md`) خصوصاً متن فارسی.
3. سپس: مراحل ۴ تا ۷ سند (حرفه‌های بیشتر، آبادانی بیشتر، صدا، بهینه‌سازی، انتشار).
