## مرحله ۰ — بررسی و امکان‌سنجی — تکمیل‌شده
- مخزن اختصاصی ساخته شد (قبلاً مخزنی برای این بازی نبود).
- Unity `6000.3.11f1` انتخاب شد و در GitHub Actions واقعاً پروژه را کامپایل کرده است.
- بیلد ابری: GameCI (`unity-builder@v4`) با مجوز پیکربندی‌شده اجرا می‌شود.
- ریسک‌های باقی‌مانده: بازبینی دیداری آخرین APK روی گوشی، متن فارسی روی دستگاه‌های متنوع، و حجم/زمان بیلد IL2CPP.

## نتیجهٔ واقعی CI روی GitHub (۱۲ اکتبر ۲۰۲۶)
- **Validate:** اجرا برای commit `a412701` موفق است.
- **Build Android:** اجرا برای commit `a412701` موفق است و Artifact APK تولید شده است.
- **Unity EditMode:** اجرا برای commit `a412701` کاملاً سبز است؛ Unity `6000.3.11f1` پروژه را کامپایل کرد و **۴۹ از ۴۹ تست** پاس شدند. پیش از آن، کمبود فضای Docker و مجوز ثبت Check Run با آزادسازی دیسک و `checks: write` رفع شدند.

## مرحله ۱ — پروژه و اولین APK — در حال تأیید نهایی
| کار | وضعیت |
|---|---|
| پروژه Unity، asmdef، manifest، تنظیمات اندروید در `BuildScript` | در CI با Unity 6000.3.11f1 کامپایل و تست شده |
| صحنه آغازین/منو، جهان سه‌بعدی، شخصیت، دوربین، جوی‌استیک | در APK ساخته شده؛ تست دستی تصویری Android انجام شده |

| معیار: اجرای واقعی Workflow + APK قابل دریافت + نصب روی گوشی | build و نصب/تصویر انجام شده؛ بازبینی دیداری commitهای جدید باقی مانده |

**مانده:** دریافت و نصب APK آخرین commit برای تأیید دیداری پالت `Unlit/Color` و محتواهای جدید.

## مراحل ۲ و ۳ — محله اول، مأموریت، ذخیره — کد نوشته شده، اثبات‌نشده
- منطق (مأموریت، پاداش، تکرار، ذخیره، آبادانی): **با ۴۴ تست واقعاً پاس شده**.
- اتصال به صحنه، UI، تعامل: فقط type-check با استاب دست‌نویس؛ در Unity اجرا نشده.
- محتوا: ۶ حرفهٔ کامل (مهندس و سازنده، معلم، پزشک و مراقب سلامت، محیط‌بان و بازیافت، کشاورز، آتش‌نشان)، ۳۰ مأموریت زنجیره‌ای، ۶ NPC، ۵ ساختمان تغییرپذیر (مدرسه، کلینیک، ایستگاه بازیافت، مزرعهٔ محله و ایستگاه آتش‌نشانی).
- زنجیرهٔ مهندس: پیدا کردن ابزار، جمع‌آوری تخته، تعمیر، رنگ‌آمیزی و پاک‌سازی/فعال‌سازی مدرسه. هر مرحله نقطه‌های تعاملی واقعی و پاداش/پیشرفت ذخیره‌شونده دارد؛ پایان زنجیره مدرسه را به وضعیت «فعال» می‌رساند.
- زنجیرهٔ معلم: پس از فعال‌شدن مدرسه باز می‌شود و شامل کتابخانه، چیدمان کلاس، باغچه، تابلوی درس و دعوت به کلاس است. برای همهٔ هدف‌ها NPC یا نقطهٔ تعامل متناظر در مولد صحنه وجود دارد.
- زنجیرهٔ پزشک: پس از اولین کلاس باز می‌شود و شامل جمع‌آوری کمک‌های اولیه، چیدمان تجهیزات، تعمیر کلینیک، سالن انتظار و بازگشایی است. پیشرفت آن ظاهر کلینیک را از متروک به بازسازی و سپس فعال تغییر می‌دهد.
- زنجیرهٔ محیط‌بان: پس از فعال‌شدن کلینیک باز می‌شود و شامل دستکش کار، پاک‌سازی، تفکیک زباله، کاشت نهال و بازگشایی ایستگاه بازیافت است. پیشرفت آن ظاهر ایستگاه بازیافت را از متروک به بازسازی و سپس فعال تغییر می‌دهد.
- زنجیرهٔ کشاورز: پس از فعال‌شدن ایستگاه بازیافت باز می‌شود و شامل بذر، آماده‌سازی خاک، آبیاری، برداشت و بازگشایی مزرعه است. پیشرفت آن ظاهر مزرعه را از متروک به بازسازی و سپس فعال تغییر می‌دهد.
- زنجیرهٔ آتش‌نشان: پس از فعال‌شدن مزرعه باز می‌شود و شامل تجهیزات ایمنی، شلنگ‌ها، بازبینی ایمنی، آزمون آژیر و بازگشایی ایستگاه آتش‌نشانی است. پیشرفت آن ظاهر ایستگاه را از متروک به بازسازی و سپس فعال تغییر می‌دهد.
- گزارش تصویری Android پس از کاهش نور، تیرگی شدید متریال‌های `Mobile/Diffuse` را نشان داد. پالت پایه به `Unlit/Color` منتقل شد تا رنگ محیط و نقاط تعامل مستقل از نور دستگاه باشد؛ این اصلاح باید با APK بعدی به‌صورت دیداری تأیید شود.
